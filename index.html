సమాచారం చేర్చేవారి కోసంFor volunteers who add updates
చేర్చే ముందు · Before adding an update
  • Read the full official notice (all PDF pages, tables and annexures), not just the headline.
  • Write only what the notice states. If eligibility, deadline or payment date is missing, say “Not specified”.
  • Mark proposals and media reports clearly; a proposal is not an approved benefit.
  • If a PDF is scanned and the text could not be fully read, choose “Scanned — needs review”.
  • Never delete a closed alert; mark it “Expired” or “Superseded” so the history stays.

Updates are saved only in this browser. Save a backup file before changing phones or clearing browser data.

ఇది ప్రభుత్వ వెబ్‌సైట్ కాదు. This is not an official government website. Every update links to the official notice — always confirm there before applying or paying anything.

Proposals, approved orders, application windows and payment announcements are labelled separately. Closed updates stay visible, marked as expired or superseded.
